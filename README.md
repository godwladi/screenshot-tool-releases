# Screenshot-Tool

Screenshot-, Texterkennungs- und Bildwerkzeug für Windows – läuft im Infobereich, ein Tastendruck genügt.

**[⬇ Neueste Version herunterladen](https://github.com/godwladi/screenshot-tool-releases/releases/latest)**

## Was es kann

- Bereich, Fenster oder Bildschirm aufnehmen (`Druck`), mit Lupe und Pixel-Koordinaten
- Editor: Pfeile, Rahmen, Text, Nummern, Marker, Verpixeln, Zuschneiden
- Texterkennung (OCR) mit Vorschau zum Korrigieren – offline, über die Windows-Sprachpakete
- QR- und Barcodes lesen, Screenshots anheften, sensible Daten automatisch schwärzen
- „Schöne Rahmen“ für Social Media, Verlauf mit Textsuche, Themes, Randleiste
- Aktualisiert sich automatisch

## Installation

1. Unter **[Releases](https://github.com/godwladi/screenshot-tool-releases/releases/latest)** bei *Assets* die passende Datei laden:
   - `ScreenshotTool.exe` – für fast alle PCs und Laptops (Intel / AMD)
   - `ScreenshotTool-arm64.exe` – nur für ARM-Geräte (z. B. Snapdragon)
2. In einen festen Ordner legen, z. B. `%LocalAppData%\Programs\ScreenshotTool\`.
3. Starten. Bei „Der Computer wurde durch Windows geschützt“: **Weitere Informationen → Trotzdem ausführen**
   (die Datei ist nicht digital signiert).
4. Einstellungen → „Mit Windows starten“ anhaken.

Voraussetzung: Windows 10 ab Version 2004 oder Windows 11. Keine weitere Installation nötig.
`F1` zeigt jederzeit alle Tastenkürzel.
